# Changelog

All notable changes to the `ooad-workflow` distribution pack are documented here.
Releases are cut with [changesets](https://github.com/changesets/changesets):
add a changeset file under `.changeset/` with your change, and the release
workflow opens a version PR on merge to `main`.

## 0.1.0

- First installable release: 8 skills (`ask-ooad`, `setup-ooad`,
  `ooad-discover`, `ooad-requirements`, `ooad-architect`, `ooad-build`,
  `ooad-verify`, `ooad-ship`) with bundled `templates/` + `references/`.
- Install via `npx skills@latest add estebanmatias92/ooad-workflow`
  (skills.sh) or as a Claude Code plugin (`ooad-workflow` marketplace).
