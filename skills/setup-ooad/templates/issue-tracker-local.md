# Issue tracker: Local Markdown

Issues live as markdown in `.scratch/`.

## Conventions

- One feature per directory: `.scratch/<feature-slug>/`
- Spec at `.scratch/<feature-slug>/spec.md`
- Tickets at `.scratch/<feature-slug>/issues/NN-slug.md` (01, 02...)
- Status on line `Status: open | claimed | resolved`

## When a skill says "publish"

Create file under `.scratch/<feature-slug>/`.

## When a skill says "fetch"

Read file at the given path.
